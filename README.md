# Syed Osama — Personal Portfolio

Premium, single-page personal portfolio built with semantic HTML, CSS, and vanilla JavaScript. No build step is needed.

## Run locally

From this folder, run `python -m http.server 8000`, then open `http://localhost:8000`.

## Content handoff

The three work cards use intentionally marked placeholders (`Untitled / 01–03`) because no project metadata was supplied. Replace those titles, descriptions, and destination links with Syed Osama’s published work when available.
